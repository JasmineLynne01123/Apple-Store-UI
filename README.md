# Apple Store UI | Macbook Pro Showcase 💻

A high-fidelity recreation of the Apple Store product page.
This project focuses on capturing Apple's signature minimalist aesthetic through precise layout techniques,
modern CSS, and responsive design.

🔗 **[Live Demo](https://jasminelynne01123.github.io/Apple-Store-UI/)**

## ✨ Key Features
* **Pixel-Perfect Recreation:** Faithfully capturing the typography, spacing,
* and hierarchy of the official Apple web interface.
* **Modern CSS Layouts:** Utilizing Flexbox and CSS Grid for a clean, structured product presentation.
* **Responsive Architecture:** Fully optimized for mobile, tablet, and desktop viewing.
* **Interactive Elements:** Custom-styled buttons and navigation wrappers to mimic a real shopping experience.

## 🛠️ Technical Stack
* **HTML5:** Semantic structure for accessibility and SEO.
* **CSS3:** Custom properties (variables), transitions, and glassmorphism effects.
* **Deployment:** Hosted via GitHub Pages.
